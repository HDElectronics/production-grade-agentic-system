Interactive handbook

Production-Grade Agentic AI System

An agentic system that survives real traffic is not one service — it is a stack of layers, each owning one failure mode. This handbook takes the reference implementation in this repository apart, one concept per page, with the real source code, the reasoning behind each decision, and a runnable toy example you can poke at in the browser.

How to read this

Every page follows the same shape: the problem → the production code → a toy example you can run right here → the failure modes it protects you from. Nothing on this site calls a network. All simulations run locally in JavaScript so you can change the inputs and watch the behaviour change.

What the system actually is

A stateful chat agent exposed as an HTTP API, sized for roughly 10,000 active users. A user registers, opens a chat session, and streams tokens back from a LangGraph agent that can call tools, remembers facts about them across sessions, persists its state in Postgres, and keeps working when the LLM provider misbehaves. Around that sit rate limits, structured logs, Prometheus metrics, LLM-as-a-judge evaluation, and a Docker/CI story.

API
FastAPI + Uvicorn (uvloop), versioned under /api/v1
Agent
LangGraph StateGraph with a chat node and a tool node, Postgres checkpointer
Memory
Short-term = checkpointed message list · Long-term = mem0ai over pgvector
Data
PostgreSQL 16 + pgvector, SQLModel ORM, pooled with SQLAlchemy QueuePool
Security
JWT (HS256), bcrypt, SlowAPI rate limits, input sanitisation
Observability
structlog, Prometheus + Grafana + cAdvisor, Langfuse traces
Quality
LLM-as-a-judge evals scoring hallucination, toxicity, relevancy, helpfulness, conciseness

Running the real thing

The handbook is standalone, but the code it documents starts with three commands:

# 1. Configure an environment (development | staging | production)
cp .env.example .env.development
$EDITOR .env.development        # OPENAI_API_KEY, JWT_SECRET_KEY, POSTGRES_*

# 2. Bring up Postgres+pgvector, the API, Prometheus, Grafana and cAdvisor
make docker-run-env ENV=development

# 3. Open the interactive API docs
open http://localhost:8000/docs

Ports once the stack is up: API :8000, Grafana :3000, Prometheus :9090, cAdvisor :8080, Postgres :5432.
